🏆 Kesimpulan Arsitektur

Path C terbukti sebagai arsitektur yang paling superior untuk sistem High-Concurrency / Flash Sale (War Ticket). Dengan mengalihkan beban Locking (penguncian) dari Database Relasional (Pessimistic Lock) ke In-Memory Database (Redis Lua Script), sistem mampu menangani lonjakan dari 76 RPS menjadi 45,000+ RPS dengan latensi nyaris 0 ms (di bawah 2 milidetik).

Database relasional modern tidak didesain untuk menangani ribuan write operation pada satu baris data yang sama secara bersamaan. Pendekatan Event-Driven dengan antrean (Queue) adalah kunci stabilitas sistem skala besar.
